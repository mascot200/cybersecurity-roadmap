# Certifications to Consider

Certifications **complement** a portfolio; they don't replace it. Pursue one only when it serves a
specific goal (a job requirement, a structured push to learn an area, an employer paying for it).

| Certification | When to consider it | Priority for this roadmap |
|---|---|---|
| CompTIA Security+ | After Level 1; a broad baseline many HR filters recognize | Optional |
| AWS Certified Solutions Architect – Associate | Before/while doing Month 7–8 if you lack AWS architecture knowledge | Optional foundation |
| AWS Certified Security – Specialty | After Level 2–3, with solid AWS + security ops experience | **Strong cloud option** |
| Burp Suite Certified Practitioner (BSCP) | After substantial PortSwigger lab work (most practitioner labs) | **Strong AppSec option** |
| OSCP | Only if you later pursue penetration testing more deeply | Optional; not required for this goal |

**Suggested timing:** BSCP around Month 5–6 (after Level 1 + extra PortSwigger practice);
AWS Security Specialty after Month 9–10.

> Names, objectives, prerequisites, prices and formats change. Always verify on the official provider site.
